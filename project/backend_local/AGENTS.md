# Instrucciones para agentes en el backend local

Antes de editar archivos de esta carpeta, lee [`CONTRIBUTING_AI.md`](CONTRIBUTING_AI.md)
y [`README_GITHUB.md`](README_GITHUB.md). El backend es una implementación local parcial;
no es el servicio original y la reconstrucción total estimada no supera el 25%.

Usa evidencia del cliente para definir cada contrato. Etiqueta lo observado,
inferido y desconocido; no modifiques cuentas ni perfiles reales; usa datos
temporales; no publiques APKs, recursos ni catálogos derivados del cliente.
El `.bat` de LAN se genera localmente con `generate_lan_launcher.py` y está
excluido de Git; publica solo el generador y sus instrucciones.
