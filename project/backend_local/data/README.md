# Datos locales requeridos

Los archivos JSON de esta carpeta se excluyen de Git. Incluyen datos de cuenta
y catálogos derivados de tablas del cliente del juego; su redistribución no se
ha autorizado ni revisado para este proyecto.

En el entorno de investigación se usan catálogos locales para Adventure,
capítulos PvE, Guaji PvE, progresión, mejoras de piezas, Lottery y recompensas.
Algunas funciones dependen de esos archivos. No se ha verificado el arranque
del backend sin ellos.

Si trabajas en una función que los necesita, obtén los datos por separado de
una copia del cliente que tengas derecho a usar y conserva el archivo solo en
tu estación local. Antes de redistribuir cualquier catálogo, verifica su
procedencia y permisos. No publiques perfiles, cuentas ni bases SQLite.
