# Local modified APK

This folder is a local drop location for the modified Spiral Warrior APK used for testing. The APK itself is distributed separately through a MediaFire link shared outside GitHub; this repository does not contain the APK or its download link.

1. Download the modified APK from the separately provided MediaFire link.
2. Place the APK file directly in this folder.
3. Keep the original APK and its backup outside this repository.

Git intentionally ignores this folder's contents. Do not force-add or commit APKs, recovered game resources, or other client packages.
